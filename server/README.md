# Console web HOTS Hosts — serveur

Administration à distance, multi-clients, des PC Windows équipés de HOTS Hosts.

## Installation sur Ubuntu / Debian

```bash
sudo ./deploy.sh
```

Un assistant en fenêtres vous guide (adresse de la console, e-mail facultatif), installe tout
(HTTPS automatique compris) et affiche à la fin le lien pour créer votre compte administrateur.

Relancez `sudo /opt/hots-console/deploy.sh` à tout moment pour : mettre à jour, sauvegarder,
réinitialiser un mot de passe, changer d'adresse ou désinstaller.

Guide complet : https://github.com/jrsmrtn/HOTS-Web-Administrated/blob/main/docs/CONSOLE_WEB.md
